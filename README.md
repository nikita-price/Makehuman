## 📖 About

MakeHuman is a standalone character generation application developed by the MakeHuman community. It focuses on humanoid mesh creation: you start from a base figure, adjust proportions with grouped sliders (gender, age, muscle, height, ethnicity), refine the head and face, apply skin textures and save or export the model. The project ships its own asset library of targets, skins, eyes, teeth, hair and clothing proxies, and it supports exporting to formats such as OBJ, FBX, DAE and STL for use in Blender, Unity, Unreal Engine and other pipelines. Recent builds include an updated asset downloader, improved rig presets and a refreshed viewport with better material preview.

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer fails with a missing DLL error | Install the latest Microsoft Visual C++ Redistributable (x64), then rerun setup. |
| App launches to a black or blank viewport | Update your graphics driver and confirm the GPU supports OpenGL 3.3 or newer. |
| Asset downloader cannot reach the repository | Check your firewall or proxy rules; allow the app through Windows Defender Firewall. |
| Model exports with wrong scale in Blender or Unity | Set the unit and scale options in the export dialog before saving the file. |
| Clothes or hair do not follow the body | Reapply the proxy after changing body targets so the asset rebuilds against the new shape. |
| Slow viewport performance with many proxies | Lower the viewport subdivision level and hide assets you are not editing. |
